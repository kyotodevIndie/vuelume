# @vuelume/cli

Command line tools from [vuelume](https://github.com/kyotodevIndie/vuelume):

```bash
npx @vuelume/cli inspect ./my-app                 # components, props, emits, slots
npx @vuelume/cli tree src/App.vue                 # template nodes, locations, editability
npx @vuelume/cli set-prop src/App.vue 1.2 size small --write
npx @vuelume/cli verify ./my-app                  # read-only safety self-check
```
